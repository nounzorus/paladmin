Features

Everything a server admin actually reaches for

Built around real moderation workflows — not a generic dashboard template with Palworld's name on it.

🖥️ Dashboard & moderation

  • 📊Real-time dashboard — FPS, uptime, in-game day, connected players, auto-refreshing every 10s
  • 👤Player management — level, ping, ID, kick, ban, and persistent per-player notes
  • 📢In-game announcements — with reusable message presets
  • 💾Save / restart / stop — scheduled shutdown with a warning message, or immediate stop
  • 🖧Optional RCON console — free-form commands per server, for when you need the escape hatch

🌐 Multi-server & access control

  • 🗂️Multi-server — manage as many Palworld servers as you need, each with its own credentials
  • 🔐Roles & per-user server scoping — non-admins only see what they're assigned to
  • 📜Audit log — every action recorded with who, what, and when
  • 🚫Ban view — derived from the audit log, since the Palworld API doesn't expose one
  • ✅Whitelist — opt-in per server, auto-kicks anyone connected who isn't on the list
RoleCan do
adminEverything
moderatorKick / ban / unban / announce

⏰ Automation & observability

  • 🔁Scheduled tasks — cron auto-saves and restarts, with in-game warnings beforehand
  • 📈Metrics history — background poller tracks players/FPS over time, chart over 6h–30d
  • 🔔Discord webhooks — bans, server up/down, and imminent restarts

✨ Polish

  • 🌍4-language UI — English, French, Spanish, Chinese, switchable anytime
  • 🗃️SQLite, embedded — no external database service to run or back up separately
  • 🐳One-command deploy — docker compose up and you're live
  • 🔒Hardened by default — 12h sessions, brute-force lockout, non-root container

Get started

Live in under a minute

Requires RESTAPIEnabled=True on your Palworld server — see the README for the exact config.

shell 
# 1. clone & configure
git clone https://github.com/nounzorus/palworld-admin-panel.git
cd palworld-admin-panel
cp .env.example .env
# edit .env: set PANEL_ADMIN_USERNAME + PANEL_ADMIN_PASSWORD

# 2. run it
docker compose up -d --build
1Open http://<your-machine>:8080 and log in with the admin account from .env.
2Add your Palworld server from the Servers page — host, ports, and admin password live in the database now, not .env.
3Invite your mod team: create moderator/viewer accounts from the Users page and scope them to specific servers.
